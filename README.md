# 이준호

기획부터 UI/UX를 사랑하는 풀스택 개발자 이준호입니다.

저는 웹디자인에서 출발해 팀 프로젝트에서 리드 디자이너와 팀 리더를 맡아 온 경험을 토대로, 사용자 경험과 서비스 전체의 흐름을 함께 보는 개발을 지향합니다.
프론트엔드부터 백엔드까지 아우르는 풀스택 역량을 확보해서, Next.js와 Spring을 사용하고 기획·디자인·개발 직군과 협업하여 사용자가 오래 머무는 서비스를 처음부터 끝까지 개발하고 싶습니다.
