# 이준호

기획부터 UI/UX를 사랑하는 풀스택 개발자 이준호입니다.

웹디자인과 퍼블리싱으로 시작해, 디자인 시안이 브라우저에서 실제로 움직이는 순간에 끌려 개발자가 되었습니다.
Vanilla JS → React → Next.js로 프론트엔드를 넓혀 왔고, 화면 뒤에서 데이터를 채우는 백엔드가 궁금해져 지금은 Spring 기반 백엔드까지 공부하고 있습니다.

### 🧭 지향하는 방향
- **화면에서 서버까지, 서비스를 처음부터 끝까지** 혼자서도 만들 수 있는 풀스택 개발자
- 디자이너의 눈으로 **사용자가 편한 UI/UX**를 먼저 고민하는 개발자
- 프론트 4명·백엔드 6명, 10명 팀을 리딩하며 느꼈듯 **팀과 서비스 전체의 흐름을 조율**하는 사람
- 최종적으로는 **기획과 개발을 잇는 PM/PO**로 성장하는 것이 목표입니다
